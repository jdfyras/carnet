# To decide

Open questions that only the user can settle. One `## ` heading per question, with the options and
the recommended one first. When a question is settled, move it to a numbered file in this folder
(`0001-short-title.md`) with the choice and its reason, and remove it from here.

This list is budgeted: `carnet budget` refuses it above the configured number of open questions.
A long list of undecided questions is a queue nobody reads.
